part 1: Introduction to angular 13
    1. what is angular ?
        --> angular is used for building client side application using html css and programming language like javascript and typescript.
        --> angular is not a programming language in itself like javascript , instead it is a framework which uses a programming language javascript/typescript.
        --> angular is a javascript framework which allows us to create single page application. single page application means everything will be render in single page.
        --> advantages of SPA:
            a. SPA makes the website faster and gives user reactive experience.
            b. using javascript to change the content of a webpage in dynamically is much faster than having the reach out to the server for every page change and for every new piece of data we want to display.
            c. If we do need some data from the server. we can load it in the background without making the webpage unresponsive.
    
    2. why we use angular?
        --> we can use javascript or jQuery to do the same thing which we can do with angular. But as the application grows:
            a. Vanilla or jQuery code becomes hard to maintain and we will need a way to properly structure our application.
            b. A lot of application built using vanilla javascript/jQuery is hard to test.

        --> angular gives our application a clean and loosely coupled  structure that is easy to understand and maintain.
        --> it brings a lot of utility code which can be re-used in lot of application, especially, when dealing with user navigation and browser history.
        --> application built with angular are more testable.

    3. angular versions
        1. angular js --> angular team first release angular js which is based on totally javascript and more complex to overcome this problem angular 2 is come in market
        2. angular 2 --> angular 2 is based on typescript 

        --> now the current version is angular 13.

part 4: Files and folder structure.
    1. node_modules 
        --> node_modules contains all the npm packages and dependencies required by the Angular application. It is automatically created when we run npm install.
    
    2. src 
        --> The src folder contains the main source code and resources of the Angular application.

        2.1 app
            --> The app folder contains the main Angular application logic, including components, modules, services, routing, directives and pipes.

            2.1.1 app/app.component.ts
                --> app.component.ts contains the TypeScript logic of the root component. It defines the component using the @Component decorator.
            2.1.2 app/app.component.html
                --> app.component.html contains the HTML template or user interface of the root component.
            2.1.3 app/app.component.css
                --> app.component.css contains the CSS styles for the AppComponent.
            2.1.4 app/app.component.spec.ts
                --> app.component.spec.ts contains unit tests for the AppComponent.
            2.1.5 app/app.module.ts
                --> app.module.ts is the root Angular module in an Angular 13 application. It uses the @NgModule decorator.
                --> app.module.ts is the root module of an Angular 13 application. It manages the application's components, modules, services and the root component that should be bootstrapped.

        2.2 assets
            --> The assets folder contains static resources such as images, icons, fonts and JSON files used by the application.

        2.3 environments/
            --> The environments folder contains environment-specific configuration such as development and production API URLs.
            2.3.1  environment.ts
                --> environment.ts contains configuration values used during development.
            2.3.2 environment.prod.ts
                --> environment.prod.ts contains configuration values used when the application is built for production.
        
        2.4 favicon.ico
            --> favicon.ico is the small icon displayed in the browser tab.

        2.5 index.html
            --> index.html is the main HTML page of the Angular application and contains the root component selector where Angular renders the application.

        2.6 main.ts 
            --> main.ts is the entry point of the Angular application. It bootstraps the root AppModule.

        2.7 polyfills.ts
            --> polyfills.ts provides browser compatibility support for features that may not be available in some browsers.

        2.8 styles.css
            --> styles.css contains the global CSS styles for the application.

        2.9 tests.ts

        2.10 .browserslistrc
            --> .browserslistrc specifies which browsers the Angular application should support. It helps build tools determine browser compatibility.

        2.11 .editorconfig
            --> .editorconfig helps maintain consistent coding and formatting rules across different editors and IDEs.

        2.12 .gitignore
            --> .gitignore tells Git which files and folders should not be tracked or committed.

        2.13 angular.json
            --> angular.json contains the configuration settings used by Angular CLI for building, serving and testing the application.

        2.14 karma.conf.js 
            --> karma.conf.js contains configuration for the Karma test runner used to execute unit tests.

        2.15 package.json
            --> package.json contains project metadata, npm scripts, dependencies and development dependencies required by the Angular project.

        2.16 package-lock.json
            --> package-lock.json records the exact dependency versions and dependency tree installed in the project.

        2.17 README.md
            --> README.md contains documentation and instructions about the project.

        2.18 tsconfig.app.json
            --> tsconfig.app.json contains TypeScript compiler configuration specific to the Angular application.

        2.19 tsconfig.json
            --> tsconfig.json contains the main TypeScript compiler configuration for the project.
        
        2.20 tsconfig.spec.json
            --> tsconfig.spec.json contains TypeScript configuration used for testing and specification files.

part 9: data binding in angular?
    --> data binding in angular allows us to communication between a component class and its corresponding view template

    9.1 one way data binding?
        --> in one way data binding is, when we can access a component class property in its corresponding view template.
        --> one way data binding is also , when we can access a value from view template in corresponding class property.

            a. string interpolation:
                --> string interpolation in angular is used to bind data from component class to view template. that means data flows from component to view.

            b. property binding:
                --> property binding is used to bind the property af an html element to the property or method of a component class.

            c. event binding:
                --> event binding allows us to bind webpage events to a components property or method. using event binding we can pass data from view to component.

    9.2 two way data binding?
        --> two way data binding, binds data from component class to view template and view template to component class. this is a combination of property and event binding.

part 10: what are directives?
    --> directives are simply an instructions to DOM. directives are classified into mainly two types:
        10.1 structural directives:
            --> a structural directives can change the view of a webpage by adding or removing DOM element from webpage for ex: ngIf, ngFor, ngSwitch.

            a. ngFor directive - this directive used to repeat a portion of html template once per each item from an iterable list.

            b. ngIf directive -  this directive used to repeat a portion of html template once per each item from an iterable list.

        10.2 attribute directives:
            --> a attribute directive can change the look and behavior  of DOM element for ex: ngStyle, ngClass

            a. ngStyle directive - this directive change the look and behavior of dom element

            b. ngClass directive - this directive change the look and behavior of dom element and it add class dynamically to the webpage element

part 11: Inter component communication.
    --> we can pass data from component class to view template and vice versa using property binding, string interpolation and event binding.
    --> we can also pass data from parent to child component and vice versa  for that using @input(), @output(), and @viewChild() decorator.
        a. @input() - pass data from parent to child.
        b. @output() - pass data from child to parent.
